🚀 Features

    Automatic Categorization: Sorts emails from Gmail, Yahoo, Hotmail, Outlook, Mail.ru, Yandex, and many more.

    Smart Folder Management: Automatically creates a Filtred directory to store your results.

    Real-time Statistics: Provides a colorful terminal summary of the total counts for each provider.

    Catch-all Logic: Emails that don't match specific major providers are tucked away into a Special Domains file.

    🛠️ Prerequisites

This tool is built with Python 2.7. You will need the following libraries:

    colorama

    requests

    termcolor

You can install them via pip:
Bash

pip install colorama requests termcolor


📂 How to Use

    Prepare your list: Place your email list (e.g., emails.txt) in the same directory as the script.

    Run the script:
    Bash

    python filter-tool.py

    Enter your filename: When prompted with Ur List Name :, type the name of your file and hit Enter.

    Check results: Open the Filtred folder to find your sorted .txt files.
